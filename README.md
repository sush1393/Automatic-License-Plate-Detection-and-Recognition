# Automatic License Plate Detection and Recognition

## Project Overview
This project uses YOLOv5 for automatic license plate detection from vehicle images.

## Dataset
- CCPD Dataset
- Indian License Plate Dataset

## Model
- YOLOv5s
- Trained for 20 epochs

## Results
- Precision: 0.997
- Recall: 0.976
- mAP@0.5: 0.995
- mAP@0.5:0.95: 0.828
